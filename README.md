# منصة الشطرنج وإدارة اللاعبين والأخبار

منصة ويب ثنائية اللغة (العربية والإنجليزية) لإدارة ملفات لاعبي الشطرنج والأخبار، مع دعم اللعب المباشر بين المستخدمين ونظام تقييم **Elo**.

## المزايا

- عرض وإدارة ملفات لاعبي الشطرنج والأخبار.
- دعم كامل للمحتوى العربي والإنجليزي.
- تسجيل المستخدمين وتأكيد البريد الإلكتروني بواسطة رمز OTP.
- لعب شطرنج مباشر متعدد اللاعبين مع التحقق من النقلات على الخادم.
- مباريات مصنفة وغير مصنفة، مع أنظمة الوقت والزيادة الزمنية.
- ترتيب اللاعبين وسجل المباريات وحساب تقييم Elo.
- تحديات بين المستخدمين، محادثة داخل المباراة، ورسائل مباشرة.
- لوحة تحكم للمشرفين لإدارة اللاعبين والأخبار والمستخدمين والمباريات.
- ربط حساب المستخدم بملف لاعب بعد موافقة المشرف.
- رفع صور مع التحقق من نوع الملف وحجمه.

## التقنيات

- **الخلفية:** Python وFlask 3.1
- **قاعدة البيانات:** MySQL 8+ عبر PyMySQL
- **الوصول إلى البيانات:** Flask-SQLAlchemy وFlask-Migrate
- **المصادقة:** JWT وOTP عبر البريد الإلكتروني
- **محرك الشطرنج:** python-chess
- **الواجهة:** React 19 وVite
- **واجهة الشطرنج:** react-chessboard وchess.js
- **التنسيق والحركة:** Tailwind CSS وFramer Motion

## المتطلبات

- Python 3
- Node.js وnpm
- MySQL 8 أو أحدث
- حساب Brevo اختياري لإرسال رسائل OTP في بيئة الإنتاج

## التشغيل المحلي

### 1. إعداد قاعدة البيانات

أنشئ قاعدة بيانات MySQL بترميز يدعم اللغة العربية:

```bash
mysql -u root -e "CREATE DATABASE IF NOT EXISTS chess_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

### 2. إعداد بيئة Python

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. إعداد متغيرات البيئة

انسخ ملف المثال وأنشئ ملف `.env` محليًا:

```bash
cp .env.example .env
```

عدّل `DATABASE_URL` ومفاتيح `SECRET_KEY` و`JWT_SECRET_KEY`، وأضف إعدادات Brevo عند الحاجة. لا ترفع `.env` إلى Git ولا تشارك القيم السرية.

### 4. تجهيز البيانات وتشغيل الخادم

```bash
python3 seed.py
python3 run.py
```

يُبنى تطبيق React تلقائيًا عند تشغيل `run.py`، ثم يصبح التطبيق متاحًا عادةً على:

```text
http://localhost:8080
```

ويمكن استخدام سكربت التشغيل المختصر بعد تجهيز البيئة الافتراضية:

```bash
./start.sh
```

## تشغيل الواجهة أثناء التطوير

لتشغيل Vite مع إعادة التحميل التلقائي:

```bash
cd frontend
npm install
npm run dev
```

لبناء الواجهة للإنتاج:

```bash
npm run build
```

## هيكل المشروع

```text
app/
  models.py              نماذج قاعدة البيانات
  routes/                مسارات API للمصادقة واللاعبين والأخبار والمباريات
  services/              خدمات البريد وOTP وحساب Elo
frontend/
  src/
    components/          مكونات React المشتركة
    context/              سياق المصادقة واللغة
    layouts/              تخطيطات لوحة التحكم والواجهة العامة
    pages/                صفحات الإدارة والواجهة العامة
    locales/              ملفات الترجمة العربية والإنجليزية
uploads/                 الصور المرفوعة محليًا
```

## الأمان

- لا تُحفظ كلمات المرور بنص واضح.
- مسارات الإدارة محمية بالمصادقة والصلاحيات.
- توجد حدود لمعدل الطلبات لحماية نقاط تسجيل الدخول والتسجيل والرفع.
- تُتحقق الخوادم من نقلات الشطرنج وتعتبر حالة المباراة على الخادم مصدر الحقيقة.
- لا تستخدم استعلامات SQL مباشرة؛ يتم الوصول إلى البيانات عبر SQLAlchemy.
- الملفات السرية مثل `.env` وملفات البناء والاعتمادات المحلية مستثناة من Git.

## ملاحظات التطوير

- استخدم Flask-Migrate عند تغيير نماذج قاعدة البيانات:

```bash
flask db migrate -m "وصف التغيير"
flask db upgrade
```

- حدّث `CLAUDE.md` عند إضافة نماذج أو مسارات API أو مزايا معمارية جديدة.
- اختبر مسارات المحتوى باللغتين العربية والإنجليزية عند تعديل الترجمة أو الحقول الثنائية اللغة.
